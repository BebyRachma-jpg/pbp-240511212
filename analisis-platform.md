# Analisis Komparatif Platform Web, Desktop, dan Mobile

## 1. Tabel Perbandingan Platform

| Aspek | Web | Desktop | Mobile |
| :--- | :--- | :--- | :--- |
| **Bahasa utama** | HTML, CSS, JavaScript, TypeScript | C++, C#, Java, Python | Kotlin, Swift, Java, Dart |
| **Arsitektur** | Client-Server | Standalone atau Client-Server | Native, Cross-platform, atau Hybrid |
| **Cara distribusi** | Diakses via URL melalui Browser | Installer (.exe, .dmg), Microsoft/Mac App Store | Google Play Store, Apple App Store |
| **Keunggulan** | Lintas OS, tidak perlu proses instalasi, update otomatis | Performa maksimal, akses penuh ke hardware, bisa offline | Sangat portabel, mudah memanfaatkan fitur bawaan (GPS/Kamera) |
| **Keterbatasan** | Sangat bergantung pada kualitas koneksi internet | Biasanya spesifik untuk OS tertentu (Windows/macOS) | Ukuran layar kecil, spesifikasi perangkat pengguna bervariasi |
| **Contoh aplikasi** | Google Docs, Figma (Web), WhatsApp Web | Microsoft Word, Adobe Photoshop, VS Code | Instagram, Gojek, TikTok |
